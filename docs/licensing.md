# Licensing and attribution

This repository combines original analysis code, collaborative research materials, government data, transit-agency data, and OpenStreetMap data. Those components do not necessarily share one license.

## Repository code and writing

No blanket open-source or content license has been assigned to the repository. The project was produced in a collaborative academic and program setting, so ownership and permission should be confirmed before applying a license or accepting outside reuse.

## U.S. Census Bureau

ACS data are accessed through the Census Data API. Uses of the API should identify the Census Bureau as the source and should not imply that the Bureau endorses or certifies this project. See the [Census Data API terms of service](https://www.census.gov/data/developers/about/terms-of-service.html).

Suggested notice:

> This product uses the Census Bureau Data API but is not endorsed or certified by the Census Bureau.

## OpenStreetMap

OpenStreetMap data are distributed under the Open Database License (ODbL). Maps or databases derived from OSM should include appropriate attribution to OpenStreetMap and a link to its [copyright and license information](https://www.openstreetmap.org/copyright).

Suggested attribution:

> © OpenStreetMap contributors

## Transit data

GTFS files remain subject to the terms of their publishing agencies. The repository does not redistribute the archived feeds and does not grant reuse rights for them. Source pages are listed in `data/external/gtfs/gtfs_locations.txt`, beginning with the [MTA developer resources](https://www.mta.info/developers).

## Hospital and boundary data

The hospital layer originates from the New York State Department of Health. Census block groups and borough boundaries also retain their source-specific terms and attribution requirements. Exact source releases should be recorded in a future archival deposit where the current documentation identifies a provenance gap.

## Before assigning a repository license

Confirm:

1. which code was written by each project contributor;
2. whether program-produced paper or presentation material can be redistributed;
3. whether derived spatial datasets trigger source-license conditions; and
4. whether an institutional or course policy limits relicensing.

After those questions are resolved, a code license and a separate documentation/data license can be selected deliberately.
