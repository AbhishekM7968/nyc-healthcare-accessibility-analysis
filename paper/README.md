# Paper

This folder is reserved for manuscript files associated with the NYC Healthcare Accessibility study.

The final SRA paper is not included in this repository because it was created using program resources. No unavailable manuscript is referenced or reproduced here. The existing subfolders may be used for manuscript text, approved figures, and supplementary material if permission to share those files is available later.

Project methods and research decisions are documented in [`../docs/`](../docs/), while final tables and graphics are stored in [`../results/`](../results/) and [`../figures/`](../figures/).
